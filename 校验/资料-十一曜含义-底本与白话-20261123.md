# 资料：十一曜「代表什么」——底本与白话转写（2026-11-23）

> 目标：给「星曜释义」找**每颗星代表什么含义**（人物、性情、身体、事象），不是天文定义、也不是化曜。
> 检索结论：现代七政课程（如九紫辰《果老星宗入门图示》、各公众号讲义）大多是付费/公众号内文，
> 本轮抓不到正文（微信需验证、知乎 403、360doc 超时、archive.org 不可达）。
> 公开可读、且逐曜成段讲「代表什么」的底本，是这本：
> **《星命溯源・参差星性》**（清・佚名，识典古籍全文：https://www.shidianguji.com/book/SK1603/chapter/1m1emj69cpdf7）
> 它不是现代人写的，但正是现代课程反复引用的那一套"星性"骨架。

## 1. 原文（逐曜，照录）

> 七政四余，各有不同。木主文而繁大，主暴而往，土主厚而迟愚，金主刚而寡爱，水主快而不定。
>
> **日**配父加主星同主贵，吉星引从则父贵。经曰：照命守身，形容圆满，性温和，重言语，迥异常人，自幼不偏。
> 若孛会，主劳瘵，在官宫主贵，在福宫一身安闲，在五宫独行，只一男两星两男，三星三男。
>
> **月**配母，吉星引从则母贤。妇人守月度，无要星混杂，则有貌。男人值月守命，喜与木德同行，好容仪，
> 主文章艺术，心慈无毒，居官利官，若无官有寿。
>
> **火**乃子曜，分昼夜，面微黄，眉疏，言快气豪，面上小下大，宜武职。若昼生恶肌肤，眼大，损妻损财，
> 经营宰割之辈。
>
> **土**主安静，为主守命，主心地宽厚，利阳宫。昼生鼻大，寡言多怪，硬直有胆，顺行入庙荣贵。
>
> **金**星主洁净好容貌，目秀眉疏，面色红白，身不长，声响亮，善音律，多淫多技。若照命临身，有武将之象，
> 又为妻星，遇火罗则伤妻，遇水合格，有俊秀文章。
>
> **水**星主文，聪明智巧，性情不定，亦主温柔，可方可圆，在乐宫利官，若为吏亦利。
>
> **气**守命主性慈善，言语分明，坦易无妒，善谨守，少病有寿，好佛老，若近身星，或主孤寡。
>
> **孛**守命，主言粗胆大，有谋为，多奸诈，在未亥子，主富，大旺，主克子。
>
> **罗**守命，性格高傲，胆大不耐是非，无妒心，喜日生，在阳宫乐旺地，在阴宫主煎熬。但男以金为妻宿，
> 而罗乃火余，能伤金，若此星旺，恐伤妻。
>
> **计**守命，性勇，面如火，胆大多奸吝，喜居巳戌，忌夜坐，在太阴宫则怒，与他宫不同。

## 2. 白话转写（每曜一句「代表什么」）

| 曜 | 原文关键词 | 现代白话（转写稿，可改） |
|---|---|---|
| 太阳 | 配父·主贵·性温和·重言语 | 父亲与贵气；性情宽和、说话有分量；落在命身，人显得端正体面 |
| 太阴 | 配母·有貌·文章艺术·心慈 | 母亲与容貌；心软、有文才艺事；男命配木更秀气 |
| 木 | 主文而繁大 | 文教与体量：学问、名声、气派大；"繁大"也带铺张、慢 |
| 火 | 子曜·言快气豪·宜武职 | 行动与火气；说话快、气盛、适合武职；昼生怕伤皮肤，也主损妻财 |
| 土 | 安静·心地宽厚·寡言多怪·硬直 | 稳重与固执；心厚但不爱说、想法多；硬气、有胆 |
| 金 | 洁净好貌·善音律·多淫多技·妻星 | 容貌才艺与婚姻；爱美、会玩、情欲重；女命看夫、男命看妻 |
| 水 | 主文·聪明智巧·性情不定 | 聪明与机变；能说会算、圆滑；心性不定 |
| 紫炁 | 慈善·言语分明·好佛老·孤寡 | 慈善与出世；话讲得清、不妒；近宗教、清高，也主孤 |
| 月孛 | 言粗胆大·多奸诈·克子 | 胆大与心机；说话粗、敢做、心思多；主克子 |
| 罗睺 | 高傲·胆大不耐是非·伤妻 | 傲气与冲撞；受不得闲话、敢顶；火余克金，主伤妻 |
| 计都 | 性勇·面如火·多奸吝 | 勇与计较；面相带火气、胆子大、心里算得细 |

## 3. 与 App 现有文案的差别

现有一列「古义」是四字关键词（人君·恩泽·光明），好处是省地方；坏处是**看不出"代表人什么"**。
上表能回答用户真正会问的：这颗星管父亲还是母亲？管财还是管病？我这个人火重是什么样？

## 4. 还没解决的

- 现代课程的原文（《果老星宗入门图示》等）本轮读不到，上面白话是我按《参差星性》转的，不是课程原文。
- 《参差星性》是清人辑本，与《张果星宗》各星〈总论〉互有出入；若要做"一曜一条"，还需逐条对齐。
- 四余的「余奴」身份（炁＝木余、孛＝水余、罗＝火余、计＝土余）在这本里只出现于「罗乃火余」一句，其余要另取。
