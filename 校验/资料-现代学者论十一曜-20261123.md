# 资料：现代学者论「十一曜」（2026-11-23）

> 用途：给「星曜释义」找**现代学者**（天文学史 / 科学史 / 宗教学）对七政四余十一曜的释义。
> 与上一稿的区别：`资料-现代口径-20261123.md` 里我把「十干化曜」当成十一曜的现代口径，那是两类东西
> （化曜是年干化出的名号：天禄、天暗…；十一曜是七政＋四余本身），本稿不再混用。
> 另：`校验/资料-七政古义今义.md` 已收古籍原文；本稿只记学术层。

---

## 0. 先给结论

现代学术对十一曜做的「释义」只有三层：

1. **宗教名号**——道经里十一曜星君的正式称呼（《罗天大醮仪》一系）；
2. **天文定义**——七政是实体，四余是隐曜/计算点，各自对应什么几何量；
3. **来源考据**——四余从印度九曜到中土四余的裂变过程。

**学术界没有做第四层：逐曜的"性情释义"。** 星曜主什么吉凶、什么性格，在学术著作里属于"星占学内容"，
学者的处理方式是**记录并注明出处**，不重新解释，也不背书。所以想要"现代学者版的十一曜性格表"，
在学术界是不存在的；能拿到的是"这十一颗各是什么、从哪来、古人怎么用"。

这跟命理从业者的口径是两条线，不要互相代替。

## 2. 十一曜的宗教名号（钮卫星引《道门定制》卷 3《罗天大醮仪》）

原文列「黄箓罗天一千二百分圣位」第十七状：

| 曜 | 道号全称 | 备注 |
|---|---|---|
| 太阳 | 日宫太丹炎光郁明太阳帝君 | 实体 |
| 太阴 | 月宫黄华素曜元精圣后太阴元君 | 实体 |
| 木 | 东方木德始阳青皇上真道君岁星真君 | 实体 |
| 火 | 南方火德丹灵赤皇上真道君荧惑真君 | 实体 |
| 金 | 西方金德太素少阴白皇上真道君太白星君 | 实体 |
| 水 | 北方水德太冥阴元黑皇上真道君辰星真君 | 实体 |
| 土 | 中央土德祖炁中皇上真道君镇星星君 | 实体 |
| 罗睺 | 交初罗睺神首建星真君 | 隐曜 |
| 计都 | 交中计都神尾坠星真君 | 隐曜 |
| 紫炁 | 天一紫炁道星真君 | 隐曜 |
| 月孛 | 太一月孛彗星真君 | 隐曜 |

钮卫星的定性：日月五星为「显曜」，罗、计、炁、孛为「隐曜」，后者后来通称「四余」。

## 3. 四余的学术定论（钮卫星据《七曜禳灾诀》考定）

### 3.1 罗睺

- 汉译佛经里多音译「罗睺」，也有意译「蚀神」「蚀神头」「黄幡」「太阳首」。
- 《七曜禳灾诀》：「常隐行不见，逢日月则蚀……常逆行于天……十八年一周天退十一度三分度之二」。
- **钮卫星考定：罗睺 = 白道与黄道的升交点，逆行于天。**（《天文学报》1994 那篇即为此考）

### 3.2 计都

- 意译「彗孛」「彗星」「长尾星」「豹尾」「蚀神尾」「太阴首」。
- 《七曜禳灾诀》：「常顺行于天……凡九年一周天差六度十分度之三」。
- **钮卫星考定：计都 = 月球轨道的远地点，顺行于天。**
- 后来月孛继承了「远地点」这个位置，计都才转成另一个黄白交点。

### 3.3 沈括的另一种说法（学术上并列，不判对错）

《梦溪笔谈》卷 7：「西天法罗睺、计都，皆逆步之，乃今之交道也。**交初谓之罗睺，交中谓之计都**。」
钮卫星按：沈括的「交初」是白道与黄道的**降**交点，「交中」是**升**交点；并指出从北宋早期起，
「罗计=两个交点」的两种定义并行流传：一种同沈括，一种认为罗睺升、计都降。
**造成唐宋两种理解分歧的原因，钮卫星明说「目前尚无法给出明确判断」。**

### 3.4 月孛

- 唐末已进入罗天大醮天神体系（杜光庭 907 年《李延福为蜀王修罗天醮词》「月孛行于井宿」，钮卫星用行度验算吻合）。
- 天文定义：月球轨道远地点，周期约 8.86 年（「六十二年而七周天」）。
- 赵友钦《革象新书》卷 3 给了四余的标准定义（钮卫星称其「可以看成是给出了四余的标准定义」）。

### 3.5 紫炁

- **本土道教引入的一曜**，不是印度来的；「紫炁」这个名称与罗、计完全不同，有明确本土色彩。
- 钮卫星的推断：紫炁被称作「闰余」，而「闰余」正是太一推法里的关键中间量；术士熟悉闰余推算，
  于是把九曜改造成十一曜。
- 天文含义：**起于闰法，约二十八年周天**（赵友钦《革象新书》原文：「夫紫炁者，起于闰法，约二十八年而周天」）。
- 钮卫星的解释：一岁之闰 = 回归年与 12 个朔望月之差（10 天多），约 28 年阴阳历重新对齐，这就是紫炁周期；
  「它的天文含义在几何意义上不明确，可作代数上的解释」。
- 与韩国百科（28 年、无对应天体、清《时宪历》删除）互证。

## 4. 十一曜逐曜的「学术释义」能到什么程度

| 曜 | 学术能给的解释 | 学术给不了的 |
|---|---|---|
| 太阳 | 七曜之一，实体；道号太阳帝君；星占中为君父之象（钮文引古籍处） | 现代"自我"义（那是心理占星） |
| 太阴 | 实体；太阴元君；月为后母、借光盈亏 | 现代"情绪"义 |
| 木 | 实体；岁星星君；仁、寿（古籍） | 现代"扩张/幸运" |
| 火 | 实体；荧惑星君；礼、燥、兵（古籍） | 现代"行动力" |
| 土 | 实体；镇星星君；信、厚重、迟（古籍） | 现代"责任/时间" |
| 金 | 实体；太白星君；义、肃杀、妻星（古籍） | 现代"爱与美" |
| 水 | 实体；辰星星君；智巧、无定（古籍） | 现代"沟通" |
| 罗睺 | 隐曜；升交点（钮考）；蚀神头；十八年周天逆行 | 逐曜吉凶释义 |
| 计都 | 隐曜；原为月球远地点（钮考），后为黄白交点；彗星/豹尾 | 同上 |
| 紫炁 | 隐曜；本土引入；闰法，28 年周天；无几何对应 | 同上 |
| 月孛 | 隐曜；月球远地点，8.86 年；唐末已入道教醮仪 | 同上 |

**一句话**：学术界的"释义"是**定名、定性、定源**；术数界的"释义"是**定吉凶、定性情**。
两者都有价值，但不能互相冒充。

## 5. 对 App「星曜释义」的直接可用点

1. **四余那四行可以写实**：
   - 罗睺＝黄白升交点（钮卫星考；另有沈括一系作降交点，学界未判对错）；
   - 计都＝原为月球远地点，后转黄白交点（这是"计都曾被误当月球远地点"一说的学术版，比旧文案准确）；
   - 月孛＝月球远地点，8.86 年；
   - 紫炁＝起于闰法，28 年周天，无几何对应，本土道教引入。
2. **十一曜名号可用**（太阳帝君、太阴元君、五德星君、神首/神尾、天一/太一）——这是"古称"里最正式的一套，
   比 App 现在只有「日/月/炁/罗/计/孛」单字更完整。
3. **「古／今」的今义要么删、要么明确标成"西式心理占星"**——学术界没有任何一位把"太阳＝自我"当作七政的现代释义。
4. 旧文案 FOUR_AT 里「罗睺＝火星之余奴」这类是《张果星宗》的**术数体系内部说法**，不是学术定论，两者要分清。
